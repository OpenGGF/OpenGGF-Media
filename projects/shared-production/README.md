# Shared production workflows

Historical snapshots of the capture, input-authoring, trace-rendering and highlights
skills, plus the generic `reel_build.py` helper used for zone reels. The helper
expects an `edit_list.csv` beside it and footage in its parent directory.

These instructions document the production method. They are not agent setup for
this archive. Links in the original skill snapshots refer to the matching OpenGGF
tree; see the pinned links in the [source references](../../docs/source-references.md).
