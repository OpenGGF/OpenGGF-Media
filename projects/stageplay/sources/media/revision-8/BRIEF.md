# Stageplay revision eight — approved aesthetic revision

Audience: first-time creators. User approved proceeding with Opus 5.5's review,
using Sol subagents. Preserve native Puppet motion and clear named dialogue.

Lead with the completed short, then one continuous annotated pass, one measured
A/B example, and a concise invitation to open the bundled sample. Aim roughly
75–90 seconds. A longer readable explanation is preferable to one-second captions.
Do not replay the same first jump in seven unrelated chapters. Use less text,
stronger connection between instruction and action, and readable source-time cues.
Keep the navy/cream/gold condensed typography, enlarge the game, and avoid animated
fractional zoom. Prefer a 1920×1080 canvas with a 1280×896 (4×native) viewport.

Scene: retain the teamwork premise, acknowledge Tails can fly, add a visible
Sonic reaction and align the count-in with takeoff. Use supported input intents.
Dialogue belongs in clear space and must avoid the jump arcs; moving every line
to the top without checking the whole movement is not an accepted fix.
Do not add a longer obstacle course merely to make the climax physically bigger.
Extend the scene with an approximately eight-second moving-platform tail for the
end card rather than reusing the climax a third time.

Sound: use one continuous ROM music bed without restarts, with separately captured
native SFX where available. Never layer the existing combined soundtrack over a
second music bed. Measure sectional loudness and encoded true peak; technical
metering does not certify perceived sound or physical listening.

Review limitations: Opus inspected source timings, frame samples and loudness;
it did not perform normal-speed playback or hear audio. Final production still requires full-motion
review, validation and source archiving. No new engine feature is
required unless an actual blocker is found and justified.
