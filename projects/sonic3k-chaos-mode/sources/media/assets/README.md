# Chaos Mode promo editorial assets

Local task media, copied from the same owner’s earlier ROM-backed promos. No artwork or audio is placed in the repository or mod. `provenance.json` records each original path and SHA-256.

- `glyphs/`: S3K ROM title-card letters and ring poses, decoded for Typing of the Hedgehog (2026-10-10). The title alphabet only has A B C D E F G H I K L M N O P R S T U V Y; cards never invent missing ROM glyphs.
- `plate-font.txt`: original Typing of the Hedgehog 5×9 pixel face for small captions, credits and jokes.
- `audio/*.wav`: ROM-derived Flappy Tails promo stings (2026-10-08), cut from actual captured native audio. `data-select.wav` is S3K music0x2F, mus_DataSelect, rendered through OpenGGF’s SMPS driver for that promo. These are editorial beds/stings; they do not certify synchronous Chaos gameplay audio.
- `aiz-background.png`: actual native AIZ screenshot at presentation2750 of the successful Chaos Mode title/menu launch capture (2026-10-13,source5f724050b). It is a darkened static decorative background for editorial cards, never gameplay motion evidence. Rendering preserves its aspect; 320px footage sits centred in a400px canvas.

The cards follow Flappy/Typing’s navy/gold framing, ROM lettering, short scale overshoot and restrained cut flashes. Fictional character reviews are marked FICTIONAL CRITICS. The final assembler owns gameplay/audio synchronization and media verification.
